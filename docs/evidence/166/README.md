# 客户端安装辅助命令隐藏运行

2026-10-24，[#458](https://github.com/marci-labs/LabelFrame/issues/458)。用户已确认前轮1.4.6验收通过，#451/#452结项；本轮仅隐藏客户端安装/覆盖升级的安全退出预检控制台。

## 实现与本地检查

- 使用原生 x64 WixQuietExec，同步执行固定系统路径 PowerShell，前置属性赋值动作与原动作条件相同。输出写入 MSI 日志，失败仍阻断，服务 PID 与打印预检逻辑不变。正常向导和 UAC 保留。
- 实际MSI断言验证DLL类型、x64入口、命令属性类型与先后顺序、固定路径、格式化后可解析，以及服务角色回归。旧1.4.6包在新增隐藏执行断言失败；1.4.7通过结构与依赖检查。
- 本地Release build0警告0错误，完整.NET1285项通过（排除Perf/Soak）。前端无修改，本轮本地未重跑前端；CI仍执行全套门禁。

## 隔离 Windows

按clean-win-vm纪律测试前后还原baseline-clean-winrm。对最终MSI的真实ShutdownWinHost DLL动作使用测试命令检测子进程控制台，并验证0/非0退出码；未修改候选包，也未触碰用户本机安装。

| 场景 | 控制台句柄 | MSI动作结果 |
|---|---|---|
| 同环境直接创建可见PowerShell（正对照） | 30474412，非零 | 不适用 |
| QuietExec执行成功命令 | 0，无控制台 | 1，成功 |
| QuietExec执行退出码7的命令 | 0，无控制台 | 3，失败 |

结果：[quiet-result.json](quiet-result.json)。这是无控制台创建的进程探针，不冒充用户安装向导人工观察。首轮验收脚本的COM调用/日志参数错误已修正后重新执行；日志复制因仍被MSI会话占用而失败，结果JSON已导出，未将该复制记作成功。

实际MSI覆盖安装：先安装1.4.6并运行客户端，再升级1.4.7，两次退出码均0；测试计划任务重新打开后新实例API正常、注册表安装版本1.4.7、更新服务Running。见[upgrade-result.json](upgrade-result.json)。重新打开不作为安装完成自动启动证据。最终还原基线并核验无测试目录/任务/更新服务。
