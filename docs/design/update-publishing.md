# 客户端更新发布管理

任务：[#476](https://github.com/marci-labs/LabelFrame/issues/476)。本篇替代 Windows/Android 更新设计中独立发布表单与专用管理口令的描述；设备安装安全规则不变。

## 权限与部署

用户明确批准移除更新发布、暂停、状态读取的专用口令与 HTTPS/回环限制。管理网页不保留密码框、解锁、前端秘密或伪登录；可信内网同源 HTTP 即可使用。保留 Origin 与 Fetch Metadata 的跨源拒绝；无 Origin 的非浏览器调用允许。这不是身份认证，任何可访问接口的人都能管理发布，部署须限制可信网络。HTTPS 仍推荐用于传输保护。

下载中心默认下载页及包下载保持匿名可访问。未来管理端统一 admin/guest 权限须单独立项并在服务端实施，普通用户下载为明确保留能力；本轮不加入账户或角色分支。

旧 PDA 的人工恢复验证曾以带 Bearer 的 GET /api/android-updates 成功作为身份凭据。用户进一步确认不保留人工故障恢复能力，必要时人工重装；带 Authorization 的该旧请求固定拒绝，不能把匿名列表读取成功误当管理员验证。新管理 UI 不发送凭据。正常升级后的自动版本/配置/健康核验不属于人工恢复，继续保留。覆盖安装不保证清除故障状态；卸载重装存在配置及作业数据丢失风险，不由产品自动执行。

## 列表与确认

Windows / PDA 客户端更新共用一个发布交互组件，原上传列表保留下载、二维码及删除，增加发布状态与就地操作；不再有另一份选包表单、设备 ID 或全量勾选框。上传只提供下载草稿，不产生发布。

列表按包实际 SHA256 关联不可变发布记录，不按文件名猜测已发布。草稿被删除后原发布快照仍有效，历史发布收在折叠区且仍可暂停。原有指定设备批次的范围原样展示，不伪称全量；新发布默认全部兼容设备。

点击发布先复制临时快照并调用真实包校验器，返回真实版本、架构/ABI、摘要与兼容性；只在校验通过后出现一次确认。提交携带确认的 SHA256，发布复制到独立快照后再次校验、比对摘要，不一致拒绝并重新确认，不发布被替换的草稿。取消预览不生成发布记录；临时文件必须清理。

保留既有多发布规则：两平台分别从未暂停且兼容的发布中取最高版本，Android 同版本按发布时间排序。不引入全局唯一发布、不自动暂停旧版、不改变设备筛选或降级保护。文案明确不是操作系统或服务端更新。

暂停只能阻止后续符合暂停检查时点的领取/安装，不撤销已安装或已经提交系统的安装。PDA 始终需要系统确认；Windows 沿用本地已选策略与业务保护。

## 兼容与回退

新增管理预览/列表端点不影响旧下载接口。发布请求摘要字段为兼容新增，旧调用不带摘要仍按原校验链执行，新 UI 必须携带。既有发布记录无需迁移；回退程序后专用管理口令要求恢复，已发布快照仍有效。前端失败或发布结果未知时重新读取状态再操作，不能重复提交猜测成功。
